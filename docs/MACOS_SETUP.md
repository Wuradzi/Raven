# Встановлення Raven на macOS

Повернутися до [README](../README.md). Команди виконуються в Terminal із кореня
клонованого репозиторію.

> **Статус: ПЕРЕВІРЕНО ЧАСТКОВО (перший живий тест 09.11.2026, Apple Silicon, macOS 27.2).**
> Підтверджено за журналом сесії: `pip install -r requirements_mac.txt` без конфліктів, розпізнавання голосу
> через Groq (`stt.backend=groq`), відповіді Gemini, озвучення через `say`, вебпошук, запуск і штатне закриття
> Native UI (`python main.py`). **Ще не перевірено:** дії (відкриття програм, медіаклавіші, блокування екрана,
> знімок), вигляд вікна на Retina, звучання голосу Lesya, Intel Mac, локальний Vosk. Дозволи Універсальний доступ і
> Запис екрана на момент перевірки були не видані. Решту проходьте за [чеклістом](#7-ручний-smoke-тест-на-mac).
>
> **Важливо:** на Mac профіль `stt.backend=auto` обирає експериментальний `edge/sherpa-onnx`, для якого немає
> ні пакета, ні моделі, тож голос «мовчить». Задайте `"backend": "groq"` у `stt` (потрібен `GROQ_API_KEY` у `.env`).

## 1. Що працює на macOS і що ні

| Можливість | macOS | Як реалізовано / чому |
|---|---|---|
| Розмова (LLM), текстовий режим, пам'ять, нотатки, нагадування, файли, веб | працює | кросплатформний Python |
| STT через Groq (хмара), Vosk | працює (потребує мікрофона й дозволу) | `sounddevice`/PortAudio; Vosk 0.3.44 — остання версія з macOS-колесом |
| Озвучення | працює | системна `say` (голос Lesya, uk_UA), програвання `afplay` |
| Відкрити програму / файл / браузер | працює | `open`, `open -a`; програми з `/Applications` індексуються автоматично |
| Гучність, вимкнення звуку | працює | `osascript` (без додаткових дозволів) |
| Пауза, наступний/попередній трек | працює, якщо дозволено | системні медіаклавіші через `pyobjc` (Quartz); потрібен дозвіл «Універсальний доступ» |
| Заблокувати екран | працює, якщо дозволено | `Ctrl+Cmd+Q` через `osascript`; потрібен «Універсальний доступ»; результат не перевіряється |
| Знімок екрана | працює, якщо дозволено | `screencapture`; потрібен «Запис екрана»; зберігається в `~/Pictures/Raven` |
| Вимкнення комп'ютера / скасування | **вимкнено** | на macOS немає безпечного еквівалента без sudo; відповідь: «недоступно на цій платформі» |
| Керування вікнами (згорнути/закрити/фокус), «показати робочий стіл», завершення процесів | **вимкнено** | навичка `windows` має `platforms: ["windows"]`: `pywin32`/`pygetwindow` і Win+D не мають безпечного аналога |
| Режим «робота» (workplace) | **вимкнено** | Windows-залежний (`win32gui`, ярлики `.lnk`) |
| Inventory дисків для пошуку файлів | не реалізовано | пошук працює в `user_directories` |

Вимкнені навички не завантажуються (`platforms` у `skills/*/manifest.json`), тож Raven
чесно відповідає, що навичка недоступна, і не падає. У маніфестах macOS позначається
значенням `"darwin"` (псевдоніми `"macos"`, `"mac"` теж приймаються).
Безпека не змінена: підтвердження, довіра до STT і «запит передано ≠ виконано» діють так само;
медіакоманди, блокування й знімок відповідають, що **надіслано**, а не що виконано.

## 2. Homebrew і системні залежності

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install python@3.12 portaudio
```

- **python@3.12** — еталонна версія (підтримується 3.10+).
- **portaudio** — для `sounddevice` (мікрофон). Колесо `sounddevice` для macOS містить
  PortAudio, тож пакет Homebrew — запасний варіант, якщо імпорт не вдається.
- **ffmpeg** і **tesseract** Raven не потребує. Tesseract — лише для необов'язкового
  vision-стеку (`--with-vision`): `brew install tesseract tesseract-lang`.
- Xcode Command Line Tools (`xcode-select --install`) потрібні, лише якщо pip мусить
  збирати пакет із вихідного коду.

### Колеса Apple Silicon та Intel

Перевірено за метаданими PyPI 08.11.2026 (не встановленням на Mac):

- Усе основне (`numpy`, `psutil`, `rapidfuzz`, `sounddevice`, `lxml`, `pyobjc-*`) має
  колеса macOS для arm64; для Intel — `numpy`, `psutil`, `rapidfuzz`, `lxml`, `sounddevice`, `ctranslate2`.
- **vosk**: 0.3.45 не має macOS-колеса, тому для macOS закріплено `vosk==0.3.44`
  (universal2). У `requirements_mac.txt` закріплено `vosk==0.3.44`; Windows і Linux мають свої файли.
- **cryptography ≥ 49** має macOS-колеса лише arm64, тому для Intel Mac
  `requirements_mac.txt` обмежує версію `<49`.
- **onnxruntime** (залежність `faster-whisper`): найновіші колеса лише Apple Silicon, macOS 14+;
  на Intel pip шукатиме старішу версію. Локальний Whisper на Mac необов'язковий — основний STT
  зараз Groq. Якщо його не ставите, `stt.backend` залишайте `groq`/`auto` і не вмикайте Whisper.
- Не встановлюються на macOS (винесено маркерами): `pywin32`, `PyGetWindow`, `pyautogui`, `pyttsx3`.

## 3. Установка

Рекомендовано скрипт (не використовує sudo, не друкує й не зберігає ключі, не перезаписує
існуючі `config.json` та `.env`):

```bash
git clone https://github.com/Wuradzi/ValleRa.git Raven
cd Raven
bash scripts/install_macos.sh
```

Параметри: `--install-brew-deps` (виконати `brew install`), `--with-whisper`, `--with-native-ui`,
`--with-vision`, `--check-only` (лише перевірка). Інший Python: `RAVEN_PYTHON=/path/python3.12 bash scripts/install_macos.sh`.

Ручний еквівалент:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements_mac.txt
[ -f config.json ] || cp config.example.json config.json
[ -f .env ] || cp .env.example .env
```

Ключі (`GROQ_API_KEY`, `GEMINI_API_KEY`) впишіть у `.env` редактором. Не передавайте їх у
командному рядку й не копіюйте `.env`, `data/`, `config.json` або `.venv` з Windows.

## 4. Голос відповідей (Lesya)

Системні налаштування → Універсальний доступ → Промовляти вміст → Системний голос → Керувати
голосами… → **Ukrainian (Lesya)**. Перевірка:

```bash
say -v '?' | grep uk_UA
```

Raven шукає голос за `tts.voice_hint`; якщо такого немає (за замовчуванням там `Volodymyr` — це
Windows-голос RHVoice), автоматично обирає перший український (`uk_*`) голос. Якщо його немає, `say`
використає системний голос, який може не вимовляти українську. Бажано задати `"voice_hint": "Lesya"`.
Швидкість `tts.rate` (185) передається `say -r` у словах за хвилину.

## 5. Дозволи macOS

macOS видає дозволи **програмі, що запускає Raven** (Terminal, iTerm, VS Code, Claude), а не
Python. Змінюйте їх у Системні налаштування → Конфіденційність і безпека:

| Дозвіл | Навіщо | Без нього |
|---|---|---|
| Мікрофон | голосовий режим | запис порожній, STT нічого не чує; запит з'явиться при першому записі |
| Універсальний доступ (Accessibility) | блокування екрана, пауза/наступний/попередній трек | команда повідомить «операційна система відмовила в доступі» |
| Запис екрана (Screen Recording) | знімок екрана | відмова або знімок без вікон; Raven відмовить, якщо дозвіл точно відсутній |

Після видачі дозволу перезапустіть програму-хост (Terminal). Перевірка лише для читання:

```bash
.venv/bin/python tools/macos_check.py
```

Скрипт нічого не записує й не викликає запитів; статус `unknown` означає, що pyobjc-фреймворк
недоступний, а не «дозволено».

## 6. Запуск

```bash
bash scripts/run_macos.sh --doctor        # діагностика конфігурації, моделей, аудіо
bash scripts/run_macos.sh --text-only     # без мікрофона
bash scripts/run_macos.sh                 # звичайний запуск
bash scripts/run_macos.sh --setup         # майстер налаштування
```

Скрипт запускає `.venv/bin/python main.py` і передає йому всі аргументи.
Не запускайте два екземпляри Raven одночасно (мікрофон, single-instance lock).
Не запускайте Raven від `sudo`.

## 7. Ручний smoke-тест на Mac

Автоматичні тести не доводять роботу на Mac. Після встановлення перевірте та запишіть результат:

1. `bash scripts/install_macos.sh --check-only` і `tools/macos_check.py`: усі `FAIL` усунуті.
2. `scripts/run_macos.sh --doctor`: статуси Python, модулів, TTS, мікрофона.
3. `--text-only`: «котра година», «відкрий Safari», «відкрий браузер».
4. Озвучення: чутна українська відповідь; фраза не перекривається; «стоп» зупиняє `say`.
5. Мікрофон: короткий голосовий запит із Groq-STT.
6. Гучність (дві команди), вимкнення звуку, пауза/трек у Music/Spotify (дозвіл Accessibility).
7. «Заблокуй екран» (підтвердження → блокування), «зроби знімок екрана» (файл у `~/Pictures/Raven`
   не порожній і містить вікна).
8. Команди керування вікнами та «вимкни комп'ютер» відповідають, що недоступні, без помилки.
9. Intel Mac і Apple Silicon перевіряйте окремо.

## 8. Відомі обмеження

- Lesya і Vosk-колесо потребують окремої перевірки якості; локальний Whisper на Intel не перевірявся.
- Блокування екрана імітує `Ctrl+Cmd+Q`; нестандартне переназначення цієї комбінації зламає команду.
- Медіаклавіші керують застосунком, який macOS зараз вважає активним плеєром.
- Автоіндексація програм бачить `.app` лише на один рівень глибини в `/Applications`,
  `/Applications/Utilities`, `/System/Applications`, `~/Applications`.
- Псевдоніми Windows-програм (`блокнот` → Notepad) на Mac не спрацюють; додайте власні псевдоніми.
- Власний native UI (PySide6) на macOS не перевірявся: `--with-native-ui` на ваш ризик.
